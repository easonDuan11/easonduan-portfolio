# 🏎 数字媒体艺术作品集网站

一个汽车主题 · 简约个性 · 可无限扩展的个人作品集网站。
适合数字媒体艺术专业学生展示：**AI 生成 IP 形象项目**、**视频剪辑**、**汽车渲染（AI 优化）**、**3D 建模 / 动效 / 修图**等作品。

- 纯静态网站（HTML + CSS + JS），**双击 `index.html` 就能在浏览器里打开**
- 上传到 GitHub 后用 Vercel 免费部署，**全世界都能访问**
- 所有内容都集中在 **`assets/js/data.js`** 一个文件里，以后加作品只需改这一个文件

## ⚠️ 编辑 data.js 之前必看（重要）

这个网站所有内容都在 **`assets/js/data.js`** 里。用**记事本**编辑它时，注意两件事，否则网站会打不开：

1. **保存编码必须是 UTF-8**
   - Windows 11 记事本：菜单 **文件 → 另存为**，把 **编码** 那一栏选成 **UTF-8**，再保存。
   - 老版本记事本默认可能是 ANSI，会把中文存成乱码 → 网站打不开。如果出现乱码，用"另存为 → 编码 UTF-8"重新保存一次。
2. **引号必须成对**
   - 所有内容的两边都是英文引号 **"**，开头一个、结尾一个，不能少。
   - 例子：`name: "段宇珅"`（有开头"和结尾"）
   - 反例（会报错）：`name: "段宇珅`（少了结尾的"）

> 💡 更省心的办法：电脑上装一个 **VS Code**（免费）来编辑 `data.js`，右下角显示 UTF-8 就不会出错；或者只改内容，改完遇到问题直接发给 AI 工具让它修复。

**改完打不开了怎么办？**
- 别慌，网站不会坏，只是 `data.js` 里有个小错（最常见是引号少了一个）。
- 把 `data.js` 里**你改动过的那几行**复制发给 AI 工具（比如我），说"帮我修一下 data.js"，几秒钟就能修好。
- 或者：打开 `data.js`，检查你改过的每一行，引号是不是成对、编码是不是 UTF-8。

## ✏️ 第一步：改成你自己的信息（5 分钟）

打开 **`assets/js/data.js`**，找到最上面的 `profile` 区块：

```js
profile: {
  name: "你的名字",          // ← 改成你的中文名
  nameEn: "YOUR NAME",       // ← 改成你的英文名 / 昵称（首页大字）
  role: "数字媒体艺术学生",   // ← 你的身份
  focus: "AI 内容创作 × 汽车影像 × 三维设计",  // ← 你的方向
  tagline: "……",             // ← 一句话简介

  email: "you@example.com",  // ← 改成你的邮箱
  wechat: "你的微信号",
  avatar: "assets/img/avatar.svg",  // ← 换成你的头像照片
  bio: [ "第一段自我介绍", "第二段自我介绍" ],
  socials: [ … ]             // ← 社交账号，不想要的删掉一行
}
```

> 💡 改完保存，刷新浏览器就能看到。

## 🖼 第二步：换成你自己的作品图片

网站的图片都是**占位示例图**（SVG 插画），需要换成你的真实作品。

### 替换单张图
1. 把你的图片放进对应文件夹：
   - 作品封面 → `assets/img/works/`
   - IP 形象 / 表情包 / 周边 → `assets/img/ip/`
   - 头像 → `assets/img/`
2. 在 `data.js` 里把对应字段的路径改成你的文件名，例如：
   ```js
   cover: "assets/img/works/你的作品图.jpg"
   ```

> 💡 推荐图片规格：
> - 作品封面：横版 16:9（如 1920×1080 或 960×540）
> - IP 形象 / 表情包 / 周边 / 头像：正方形 1:1（如 1024×1024）
> - 格式支持 jpg / png / webp / svg

## 🎬 第三步：给作品加上视频（可选）

1. 把你的视频（.mp4 最通用）放进 **`assets/video/`** 文件夹。
2. 在 `data.js` 对应作品的 `video` 字段写上文件名：
   ```js
   video: "demo.mp4"
   ```
3. 点开这个作品，弹窗里就会自动变成**视频播放器**（封面图作为封面）。

> ⚠️ 视频文件比较大，建议控制在 30MB 以内，太大的视频建议先压缩（剪映导出时选较低码率）。
> ⚠️ **重要：视频别太大**。视频文件越大，别人打开网页加载越慢。
> 建议把视频压缩到 **20MB 以内**（剪映导出时选 1080p 或 720p、码率选低一点即可，1-2 分钟的视频压完一般只有十几 MB）。
> 目前 `assets/video/` 里的 ET5T 混剪原片有 **72MB**，本地看没问题，但**部署上线前建议先压缩替换**，否则访客要等很久。
> 压缩后直接覆盖同名文件即可，代码不用改。

## ➕ 第四步：添加新作品（超简单）

打开 `data.js`，找到 `works: [ … ]` 数组。**复制任意一个作品块**，粘贴到数组里，改一下内容即可：

```js
{
  id: "w13",                       // ← 唯一编号，别和别人重复
  category: "render",              // 分类：video视频剪辑 / render汽车渲染 / 3d三维建模 / motion动效特效 / design修图设计
  year: "2026",
  featured: true,                  // true = 显示"★精选"角标，不需要就写 false
  title: "你的作品标题",
  tags: ["标签1", "标签2"],
  tools: ["用到的工具"],
  cover: "assets/img/works/你的作品图.jpg",   // ← 封面图路径
  video: "",                       // ← 有视频就写文件名，没有就留 ""
  description: "作品简介，一两句话讲清楚你想表达什么。"
}
```

保存 → 刷新浏览器 → 新作品就出现了，并且自动出现在对应的分类筛选里。

## 🎨 改风格 / 主题色（可选）

所有颜色都在 **`assets/css/style.css`** 最上方的 `:root` 里：

```css
:root {
  --bg: #0b0b0f;          /* 背景色 */
  --accent: #ff4d00;      /* 主题色（现在是赛车橙） */
  --blue: #2ab7ff;        /* 辅助色 */
```

把 `--accent` 换成你喜欢的颜色（比如赛道红 `#e10600`、电光蓝 `#0091ff`、荧光绿 `#d4ff3d`），全站主题色会一起变。

## 🌍 上线发布：让全世界都能访问（免费）

> 方法参考了小红书的保姆级教程（Step 4-6）：**GitHub 存代码 → Vercel 一键部署**。两个都免费，注册都需要能收验证码的邮箱。

### Step 1 · 上传到 GitHub（相当于代码网盘）
1. 注册/登录 [github.com](https://github.com)，点右上角 **+ → New repository**，名字随意（比如 `my-portfolio`），选 **Public**，创建。
2. 安装 [GitHub Desktop](https://desktop.github.com/)（图形界面，适合不熟悉命令行的人）或用命令行：
   ```bash
   git init
   git add .
   git commit -m "我的作品集"
   git branch -M main
   git remote add origin https://github.com/你的用户名/my-portfolio.git
   git push -u origin main
   ```
3. 刷新 GitHub 页面，看到代码就上传成功了。

### Step 2 · 用 Vercel 一键部署
1. 注册/登录 [vercel.com](https://vercel.com)（建议直接用 GitHub 账号登录）。
2. 点 **Add New → Project**，选择你刚上传的仓库（`my-portfolio`）。
3. Framework 选 **Other**，其余默认，点 **Deploy**。
4. 等 1-2 分钟，会出现一个 **`https://xxx.vercel.app`** 的网址——复制发给任何人，大家都能打开你的作品集了！

### Step 3 · 以后更新怎么办
GitHub 和 Vercel 是**自动联动**的：以后你改了 `data.js` 或加了图片，把新文件 **push 到 GitHub**（或用 GitHub Desktop 点 Commit & Push），Vercel 会自动重新部署，一般 1 分钟内线上就更新了，不用做任何额外操作。

### 想拥有自己的域名（可选）
在 Vercel 项目设置 → Domains 里绑定你购买的域名（如阿里云/腾讯云购买），按提示配置即可。

## ❓ 常见问题

- **双击 index.html 打不开 / 白屏？** 确认没有单独移动 `index.html`（必须和 `assets` 文件夹同级）。白屏最常见的原因是：**刚改过 `data.js`**——某个引号少了一个或编码不是 UTF-8（见上面的"编辑 data.js 之前必看"）。如果页面显示"⚠️ 网页没能正常加载"，那就是 `data.js` 出错了，把改动的部分发给 AI 工具修复即可。
- **中文显示成方块？** 需要联网加载 Google 字体；离线时浏览器会用系统中文字体，不影响使用。
- **图片加载不出来？** 检查 `data.js` 里的路径和文件名是否完全一致（大小写也要一致）。
- **视频点不开？** 确认视频文件在 `assets/video/` 且 `video` 字段写的是**文件名**而不是完整路径。
